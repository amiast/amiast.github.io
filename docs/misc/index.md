*Miscellaneous* is a collection of code snippets, notes, and other files I have created together with the [kotone library](https://github.com/amiast/cpp-utility).

Originally, the kotone library would only host C++ headers. I designed these headers to be self-contained and well-documented so I could use them easily during contests.

As my knowledge expanded, I started taking notes of mathematical theorems and code snippets that I believed would appear in future contests. Unlike headers, these notes require extra thinking and do not automatically solve problems on their own. Nevertheless, I found them to be as helpful with quickly recalling concepts when I encounter them again in new problems.

With that, the kotone library has evolved from a library of implementations to a library of knowledge.
